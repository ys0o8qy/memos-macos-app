# Popup 常用功能建议

2026-09-18。目标仍是从任意应用快速记录文字和图片、保存到自己的 Memos；Day One 仅作为交互参考。已完成项目单独列出；其余优先级基于当前实现与使用路径判断，不代表已安排开发。

## 已有能力

菜单栏左键打开/收起、右键退出及进入列表/设置、自定义全局快捷键、打开时聚焦、Esc 收起、Command Enter 保存；图片粘贴/拖入/选择与缩略图移除；文字及图片草稿本地恢复、提交失败保留并可重试、默认私有；独立窗口中的列表、搜索、分页及编辑。

本轮已完成：登录时启动开关及系统实际状态、上传/保存阶段反馈、不抢焦点的成功提示、失败处理入口、账号标签补全与离线缓存。

## 建议补充

| 优先级 | 能力 | 解决的问题与建议行为 |
|---|---|---|
| P1 | 临时固定浮窗 | 对照网页、切换应用复制素材时不必反复唤起。默认仍点击外部收起；固定后允许切换应用而保持显示，Esc 仍能收起。 |
| P2 | 清空草稿 / 开始新记录 | 当前持续恢复一份草稿，放弃内容需要手工删除。提供明确操作，优先支持撤销；避免无提示丢失图片。多草稿切换后续按需求再做。 |
| P2 | 调整大小并记忆 | 当前编辑区固定尺寸，长文或多图时局促。支持合理范围内调整，限制到当前屏幕可用区域；不随输入频繁跳动。 |
| P2 | 图片详情与上传进度 | 当前有缩略图、移除及上传第几张的阶段反馈；可补充点击放大与单图字节进度；延续提交前只保存在本地的行为。 |
| P3 | 保存后继续记录 | 设置项决定成功后收起还是清空并继续输入，默认保持当前收起行为。 |

后续优先考虑“临时固定浮窗”，改善跨应用收集素材的主路径。自动后台上传、完整日历、AI 改写及多账号不作为这一轮轻量 Popup 的优先项。

## 交互质量检查

这些是现有行为的验收，不应当作新增功能：中文输入法候选态下不误提交；多屏幕、全屏应用和 Spaces 下的位置与唤起；光标实际可见；取消菜单后左键仍正常；固定模式下焦点只在主动唤起时获取；保存后正确回到之前的应用。

设计参考：[Apple Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)、[Apple The menu bar](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar)。上述具体功能及优先级是本项目的产品判断。
