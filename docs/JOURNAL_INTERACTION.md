# 记录与回看交互

参考 [Day One macOS 的时间线与右侧阅读视图](https://dayoneapp.com/guides/tips-and-tutorials/journal-views-in-day-one-for-macos/)，保留 Memos 的菜单栏入口、私密记录和显式服务器保存语义。

## 核心路径

- 快速记录：菜单栏打开编辑器 → 输入或粘贴图片 → ⌘Return 保存 → 成功收起，失败保留草稿并显示恢复操作。
- 窗口写入：侧栏「新建记录」或 ⌘N → 在右侧写作 → 保存 → 自动选中新记录并进入阅读。已有新建草稿时继续原草稿，不创建第二份或覆盖它。
- 回看：侧栏导航、中央时间线、右侧内容。独立分栏与明确底色避免侧栏材质的空白渲染，首次载入自动展示最新记录，时间线显示解析后的标题与摘要。记录按本地时区分月、倒序排列，未知日期保留在末尾；显示「已载入」数量，分页按钮继续读取历史。
- 搜索：⌘F 聚焦搜索，输入后延迟 300ms 请求服务器；提供清除、无结果、加载和错误状态。新建成功后清除搜索，以便显示新记录。
- 编辑：选择记录 → 编辑 / ⌘E → 完成并保存 / ⌘S 或 ⌘Return → 成功回到阅读。阅读切换不会提交更改；切换记录后，本地修改仍保留。冲突需先对照服务器版本，键盘提交与按钮使用相同约束。
- 草稿：侧栏进入共享的新建草稿；历史记录的编辑草稿仍保存在对应记录中。菜单栏与主窗口使用同一新建草稿，失败不清空。

## 快速入口与 Markdown 阅读

参考 [Day One Menu Bar Quick Entry](https://dayoneapp.com/guides/day-one-for-mac/menu-bar-quick-entry/)：菜单栏书本图标打开 440 × 420 快速记录，顶部为关闭、日期、预览、在主窗口继续和更多；底部显示私人记录及「打开」「保存」。关闭或点外部保留草稿，「打开」直接进入同一草稿，保存才提交服务器。错误和图片区域可滚动，避免撑高浮窗。

正文按完整文档解析：标题、段落、软/硬换行、引用、嵌套及有序列表、任务项、代码块、表格、链接和图片。阅读区正文 15pt、行距 6pt、内容宽度上限 680pt，代码和宽表格单独横向滚动。源码与阅读预览清晰分离。远程图片通过不带凭据的请求加载，已关联附件通过既有鉴权接口读取；失败时提供图片链接。HTML 保留为文字，不执行，不支持公式或 Mermaid。

使用锁定的 Swift Markdown / cmark 依赖；许可文件随应用放入 Resources/ThirdParty。

## 视觉与边界

沿用原生 SwiftUI / AppKit、低饱和蓝色强调色和系统深浅色；突出日期、正文和低干扰的保存状态。没有引入 Day One 的日记本、地图或位置权限。

凭据、账号隔离、附件上传、可见性、快捷键配置、登录启动均沿用原实现。主窗口默认尺寸为 1120 × 720，最小尺寸 960 × 580。

## 本次验证

`python3 scripts/validate.py test`：46 项 Swift 测试、7 项脚本测试通过。覆盖 Markdown 文档结构、嵌套列表、起始编号、换行、链接、图片位置和 popup 草稿衔接。深浅色及错误状态截图输出到 `.build/validation/renders`，渲染测试固定并断言视口尺寸。另有本地时区月份边界、未知日期排序、不同记录与新建草稿的恢复验证；保存成功/失败测试检查新记录事件，冲突测试覆盖重复键盘提交。原有 AppKit 编辑器、隔离剪贴板和快捷键测试继续执行。
