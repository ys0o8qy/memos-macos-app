# 记录与回看交互

参考 [Day One macOS 的时间线与右侧阅读视图](https://dayoneapp.com/guides/tips-and-tutorials/journal-views-in-day-one-for-macos/)，保留 Memos 的菜单栏入口、私密记录和显式服务器保存语义。

## 核心路径

- 快速记录：菜单栏打开编辑器 → 输入或粘贴图片 → ⌘Return 保存 → 成功收起，失败保留草稿并显示恢复操作。
- 窗口写入：侧栏「新建记录」或 ⌘N → 在右侧写作 → 保存 → 自动选中新记录并进入阅读。已有新建草稿时继续原草稿，不创建第二份或覆盖它。
- 回看：侧栏导航、中央时间线、右侧内容。记录按本地时区分月、倒序排列，未知日期保留在末尾；显示「已载入」数量，分页按钮继续读取历史。
- 搜索：⌘F 聚焦搜索，输入后延迟 300ms 请求服务器；提供清除、无结果、加载和错误状态。新建成功后清除搜索，以便显示新记录。
- 编辑：选择记录 → 编辑 / ⌘E → 完成并保存 / ⌘S 或 ⌘Return → 成功回到阅读。阅读切换不会提交更改；切换记录后，本地修改仍保留。冲突需先对照服务器版本，键盘提交与按钮使用相同约束。
- 草稿：侧栏进入共享的新建草稿；历史记录的编辑草稿仍保存在对应记录中。菜单栏与主窗口使用同一新建草稿，失败不清空。

## 视觉与边界

沿用原生 SwiftUI / AppKit、原有绿色强调色和系统深浅色；突出日期、正文和低干扰的保存状态。没有引入 Day One 的日记本、地图或位置权限。

凭据、账号隔离、附件上传、可见性、快捷键配置、登录启动均沿用原实现。主窗口默认尺寸为 1120 × 720，最小尺寸 960 × 580。
