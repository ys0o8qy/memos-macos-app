## 建议手工验收顺序

1. 配置服务地址和 Token，验证身份成功；输入错误 Token 时看到明确错误。
2. 在其他应用输入期间，点击菜单栏打开 Popup，输入中文、Markdown 和标签。
3. 粘贴图片、Esc 收起、重新打开，再退出重启，确认文字和图片恢复。
4. 断网点击保存，确认内容保留；联网后手动重试，服务器只出现一条私有记录。
5. 在列表搜索、分页、编辑文字/附件，确认网页端可见性和其他字段未变化。
6. 在网页修改同一记录，再从 Mac 保存旧草稿，确认出现冲突提示。
7. 在 GitHub PR 的 Checks 中下载 Universal DMG，校验 SHA-256 后安装运行，确认 Gatekeeper 提示与首次启动行为。
8. 在设置录入新快捷键，从其他应用唤起空浮窗，确认光标可见；测试取消录入、恢复默认、重启记忆，以及截图复制后 Command V 添加图片。
9. 菜单栏左键仍打开/收起浮窗；右键和 Control 点击显示菜单。取消菜单后再次左键正常，浮窗打开期间右键会先收起浮窗且保留草稿。
10. 右键菜单可打开所有记录/连接设置；无保存任务时退出并重启后草稿恢复。正在提交时选择退出应提示等待，应用继续运行，提交结束后可退出。


## 登录启动、保存反馈与标签补全

- 本轮自动测试共 38 项 Swift 和 7 项脚本测试，覆盖系统登录状态的替身测试（未更改本机登录项）、标签统计 API / 缓存 / 账号切换 / 过期响应丢弃 / 保存后刷新，以及 NSTextView 原生补全按键、撤销与 marked text 输入法路径。
- 保存测试验证收到服务端响应前不报成功、重复提交被拦截、401 保留草稿并引导设置、图片上传阶段与失败提示。提示窗禁止成为 key/main window，并使用 nonactivatingPanel。
- 本轮 Computer Use 检查仍返回 `cgWindowNotFound`。下列真实环境行为尚未验收：登录项实际注册及退出登录后自动启动、成功提示的可见位置及跨应用焦点、实际输入法和鼠标选择候选。

补充手工验收：

1. 将 app 安装到 Applications，设置中开启登录时启动；检查待批准状态及系统设置入口。注销并登录，确认仅驻留菜单栏；关闭开关后再登录不自动启动。
2. 在系统设置中撤销登录项授权，回到应用设置，确认状态即时更新，不误报已启用。
3. 保存文字与多图，观察阶段状态；成功后回到原应用继续打字，提示约 1.5 秒消失；快速重新打开浮窗时旧提示立即消失。
4. 断网/错误 Token/超限图片分别保存，确认草稿保留与操作入口；提交中收起浮窗后失败应有简短提示，重新打开能看到详情。
5. 输入 #、中文标签及 工作/子标签，使用方向键、Tab、Enter、鼠标和 Esc；中文输入法选字期间不误补全或保存。补全后 Command Z 可撤销，编辑已有标签中间时不留下重复尾部。
6. 重启并断网检查标签缓存；切换服务器或账号时不出现前一个账号的标签。Markdown 标题、代码和 URL 片段不应误触发补全。
